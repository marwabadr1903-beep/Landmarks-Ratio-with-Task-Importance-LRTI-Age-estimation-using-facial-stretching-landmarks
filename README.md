# Landmarks-Ratio-with-Task-Importance-LRTI-Age-estimation-using-facial-stretching-landmarks
In LRTI, a correlative factor is computed to each class label as an importance vector to represent the in-between labels relation. LRTI uses two ResNet-34 CNN and the local regressors use the importance vector for the final age estimation decision. 


This repository contains the PyTorch model code for the paper:
Marwa M. Badr, Reda M., Amany M.(2022)"LRTI: landmark ratios with task importance toward accurate age estimation using deep neural networks", Neural Computing and Applications, Springer.Volume 34, pages 9647–9659 (2022) https://doi.org/10.1007/s00521-022-06955-6
